Button

Generalized (recent). data-ui-state="on"/"off" are no longer tag-only — they now apply to any element. on paints the focus-ring accent (a live-in-a-set marker); off desaturates and dims (grayscale(1) opacity(0.5)) so a whole region can recede while its neighbours stay lit. .tag keeps its own bespoke off recipe (neutral fill, no filter). Drive both from one server signal to build a “spotlight” edit mode — mark editable regions on, everything else off. Note a CSS filter traps its subtree, so tag each sibling region rather than filtering one shared ancestor.

Code

<code> · <pre>

Inline <code> is a quiet monospace chip; <pre><code> is the full listing (syntax-highlit by the docs' highlight pass). Both paint from the engine surface, so they tint with the theme.

Give a panel a surface with --bg and ink with --fg.

.panel { --bg: -0.3; }
:where(.tag) { --bg: 0.16; --fg: var(--_sem-ink, -0.85); }

<pre><code>Block listing; class="css/html/js" hints the highlighter

Dense field rows

fieldset · --row-width

A <fieldset> packs its child fields onto one wrapping row; each field's --row-width sets its share (default 1). Address and payment are the classic dense forms — a lot of information, tightly.

tokeneffect

Table

<table>

Bare <table> — booktabs aesthetic: no body rules, two vibrant lines (under head, at foot). Add .num to numeric cells. Cells default to --type:-1 — the table owns its density, so you never set type per-cell. Every API table on this page is one.
